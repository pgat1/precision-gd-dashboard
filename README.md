# Precision GD — Tech Intelligence Dashboard

Internal service tech performance dashboard for Precision Garage Door.

## Deploy on Railway

1. Push this repo to GitHub
2. Go to railway.app and connect your GitHub repo
3. Add environment variable: ANTHROPIC_API_KEY = your key
4. Deploy — Railway auto-detects Node.js and runs npm start

## Local development

```
export ANTHROPIC_API_KEY=your_key_here
node server.js
```

Open http://localhost:3000
